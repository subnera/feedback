# subnera feedback

Bug reports, feature requests and release notes for **subnera**: fleet management for
IOTA Train at Home miners on macOS.

- Website and download: https://subnera.com
- Homebrew: `brew install --cask subnera/tap/subnera`
- Guides: https://subnera.com/guides
- Community: https://discord.gg/NsHBXEPwcb
- Fleet hub: https://app.subnera.com

This repository holds **issues and release notes only**. It does not contain the
application's code.

## Report a bug or ask for something

[Open an issue](https://github.com/subnera/feedback/issues/new/choose) and pick a template.
Search existing issues first. Please redact hotkeys, IP addresses and emails from
screenshots and logs, and never post a seed phrase, password, private key or install token.

## Security

Do not open a public issue for a vulnerability. See https://subnera.com/.well-known/security.txt.

## Release notes

The latest version and its notes are on https://subnera.com/download.

subnera is an unofficial project, not affiliated with Macrocosmos.
